## 👩‍💻 About Me

I'm a **Senior QA Automation Engineer / SDET** at **Broadridge Analytics Solutions** with **13+ years** in software quality and **8+ years** of hands-on test automation. My focus today is turning traditional test automation into **AI-powered quality engineering**.

- 🤖 Building **GitHub Copilot and Claude agents** that read OpenAPI specs and **generate Playwright API tests**
- 🎭 Designed a **Playwright + TypeScript framework from scratch** and led the migration from Serenity BDD
- 🛠️ **Developer-in-Test**: I debug and fix defects directly in **Vue.js** code, then cover them with regression tests
- 🚀 Wiring smoke and regression suites into **Azure DevOps CI/CD**, with results on quality dashboards
- 🧩 Built a **Playwright desktop automation package** and a **VS Code extension** for Azure DevOps PR reviews
- 🏆 Received the **Entrepreneurial Award** at Broadridge for innovation and technical leadership
- 🌱 Currently exploring **Agentic AI for testing**, **Vue.js** and **Playwright** in more depth
